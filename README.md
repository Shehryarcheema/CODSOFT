# CodSoft Web Development Internship

Front-end deliverables for a **CodSoft Web Development internship** — Level 1
tasks built with hand-written HTML, CSS, and vanilla JavaScript. Each task is a
single self-contained HTML file with embedded styling; no frameworks, no build
step, no dependencies.

## Tasks

| # | Task | File | What it is |
|---|------|------|-----------|
| 1 | Personal Portfolio Website | `Level 1 Task 1.html` | A complete portfolio site with a header/nav, About Me, Skills, Projects, Education, and Contact sections. Skills grid lists HTML5, CSS3, JavaScript, React, Responsive Design, UI/UX Design, Git, Node.js, Web Accessibility, SASS/SCSS, and Webpack. The Projects section showcases five builds — Fitness Tracker, Airline Reservation System, Online Cloth Shopping Store, Restaurant Booking System, and a Portfolio Website — each with a screenshot. Education covers a Bachelor's in Computer Science, Intermediate (college), and Matriculation (school). Contact uses mail/phone icons and links a CV (`CV Resume.pdf`). Styled entirely with embedded CSS. |
| 2 | Landing Page | `Task 2.html` | A marketing-style landing page ("Welcome to SHEHRYAR's World", tagline *"Unlocking possibilities, one passion at a time"*) with a Home/Features/Contact nav, hero section, About Me, a Services section (Advanced Technology, Personalized Services, Global Reach), and a Contact section. Styled entirely with embedded CSS. |
| 3 | Advanced Calculator | `Task 3.html` | An interactive calculator with a display, digit buttons 0–9, the four basic operators (+, −, ×, ÷), a decimal point, an equals key, and a Reset key. Implemented in vanilla JavaScript with event listeners per button, supporting chained operations (an operator pressed mid-calculation evaluates first) and full state reset. Styled with embedded CSS. |

## Tech stack

- **HTML5** — page structure and content
- **CSS3** — all styling embedded in `<style>` blocks (flexbox/grid layouts,
  hover states, responsive-ish layouts); no external stylesheets
- **JavaScript (vanilla)** — interactive calculator logic in Task 3; Tasks 1
  and 2 are static markup + CSS

## How to view

No installation or build step is required. Clone or download the repository,
then open any `.html` file directly in a browser:

```bash
git clone https://github.com/Shehryarcheema/CODSOFT.git
cd CODSOFT
# open "Level 1 Task 1.html", "Task 2.html", or "Task 3.html" in your browser
```

> Note: some file names contain spaces — keep the exact names (or URL-encode
> spaces as `%20`) when opening them from a terminal or a local server.
